## 2026-10-07 update-docker.bat Windows 原生版（第八轮会话）
- 新增 `update-docker.bat`：与 sh 版等价的 Windows 原生批处理，双击或 cmd 直接运行（ps1 有执行策略限制故选 bat）。
- **编码要点**：中文 Windows cmd 默认代码页 936(GBK)，bat 必须以 GBK 编码保存（用 Python 以 encoding='gbk' 写入）；UTF-8 保存的 bat 在默认 cmd 下中文乱码甚至解析错误。行尾 CRLF。
- 逻辑与 sh 版一致：构建失败不动旧容器；healthz 探测 200/503 均算就绪（503=账号池空仅提示）；60s 超时自动回滚旧镜像并打印日志；docker run 命令抽成 :start 子例程复用。
- cmd 端到端实测通过（构建缓存秒级、中文显示正常、容器切换、3/3 healthy、exit 0）。Git Bash 测试时输出是 GBK 字节需 iconv 转码查看，真实 cmd 窗口显示正常。
